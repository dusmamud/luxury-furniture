# Furniture — Make You Feel Luxury

Luxury furniture landing page, built with Svelte 5 + SvelteKit 3 + Vite 8 + TypeScript + Tailwind CSS v4, prerendered with `@sveltejs/adapter-static` and deployed to Cloudflare Pages.

- Mobile-first hero with real product photography, live search that filters the collections, stats, Our Collections (Outdoor Lounge Chair, Indoor Plants, Modern Couches, Modern Chair, Bamboo Swing Chairs, Hanging Light), About Us, trust features and footer with newsletter validation.
- `npm run check` — svelte-check, `npm run build` — static build in `build/`.

Live: https://luxury-furniture.pages.dev/
